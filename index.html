Central Brain Server-Side

FastAPI + Python orchestrator. Receives error telemetry, synthesizes a fix via DeepSeek-V3 or Llama 3, runs mock verification, then returns corrected logic as JSON.

FastAPI DeepSeek-V3 Llama 3 Groq Python
Edge Worker Client-Side

Vanilla JavaScript runtime that treats its own functions as mutable variables. On failure, captures state and POSTs telemetry to the Brain — then hot-swaps its logic via new Function().
